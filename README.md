Supplementary data and codes to generate the figures shown in Rowan et al., 2026 
"Contrasting ages and dynamics of unsaturated zone carbon pools at a mid-latitude karst system". 

The manuscript is currently under review in Biogeosciences (BG).

Please cite the original paper when using the data and code.

The figures are generated by running the R script "Figures_paper.R" within the enclosed folder.
